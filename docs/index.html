Is Orpheus really free? +

Yes. Orpheus is 100% free Windows software with no subscriptions, no watermarks, and no locked features.

Does it need an internet connection? +

No. Editing, vertical 9:16 layouts, color grading, and auto subtitles all run offline on your PC.

How do the local AI features work in a 39 MB installer? +

The Orpheus installer is lightweight (39 MB) so it downloads fast. Built-in tools like silence removal and 9:16 framing work immediately, while the compact local speech-to-text model (Whisper) is downloaded once on first use and stored locally — after that, everything runs 100% offline with no internet or cloud limits.

Why does Windows SmartScreen show a prompt? +

Independent free apps without a paid corporate certificate show a standard Windows notice. Click More info and then Run anyway to install.
